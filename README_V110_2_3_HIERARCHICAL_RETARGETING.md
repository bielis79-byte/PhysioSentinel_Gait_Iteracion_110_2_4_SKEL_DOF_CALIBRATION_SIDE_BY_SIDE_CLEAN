# V110.2.3 · SKEL Hierarchical Retargeting

Objetivo: impedir que SKEL reduzca RMSE mediante torsiones internas no observables. Sólo 16 de 46 q se permiten variar; el resto queda neutral. Se ajustan secuencialmente tronco, miembros inferiores y superiores y después se aplica un refinamiento pequeño. La animación 3D simplificada V104/V107 se muestra como referencia no calibrada para comparar el movimiento objetivo antes de interpretar la malla corporal.
